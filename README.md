# resiayukp.github.io

Personal portfolio site, built with Jekyll and the [Minimal](https://github.com/pages-themes/minimal) theme and hosted on GitHub Pages.

Live site: https://resiayukp.github.io

## Edit the site

* `\_config.yml`: site title, description, theme and optional profile picture
* `index.md`, `projects.md`, `experience.md`: page content in Markdown
* `assets/css/style.scss`: custom styles on top of the theme
* `assets/img/`: images
